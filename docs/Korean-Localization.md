# Craft 앱 한국어 용어와 초보자 도움말

2026-10-24 초안. **용어 선택과 도움말 집필용 자료이며, 앱 전체의 번역 완료나 기능 지원을 뜻하지 않습니다.**
사용자의 요청에 따라 공개된 Adobe 한국어 도움말과 튜토리얼을 비교했습니다. 짧은 관용 용어는
참고하고, 설명과 툴팁은 각 개념과 Craft 코드의 동작을 바탕으로 새로 씁니다. Adobe 설명문,
번역 문자열 묶음, 이미지, 아이콘이나 샘플 자료를 복제하지 않습니다. 이는 이 사용자 fork의
이번 용어 연구 범위이며 기존 공유 카탈로그의 출처나 검토 이력을 바꾸지 않습니다.

## 용어집의 구성

정본은 아래 UTF-8 TSV 파일입니다. 각 행은 영어, 우선 한국어, 적용 문맥, 초보자 설명,
참고 출처, 선택 이유를 담습니다. 같은 영어라도 의미가 다르면 문맥을 나눕니다.

| 범위 | 정본 | 내용 |
|---|---|---|
| 공통 | [ko-common.tsv](terminology/ko-common.tsv) | 파일·편집·선택·색상·화면·텍스트 기본 개념 |
| PdfCraft | [ko-pdfcraft.tsv](terminology/ko-pdfcraft.tsv) | OCR·페이지·주석·민감정보·서명·접근성 |
| DesignCraft | [ko-designcraft.tsv](terminology/ko-designcraft.tsv) | 조판·스프레드·도련·텍스트 흐름·스타일 |
| PhotoCraft | [ko-photocraft.tsv](terminology/ko-photocraft.tsv) | 픽셀·레이어·마스크·선택·색조·보정 |
| VectorCraft | [ko-vectorcraft.tsv](terminology/ko-vectorcraft.tsv) | 대지·패스·고정점·도형 연산·변환 |
| FilmCraft | [ko-filmcraft.tsv](terminology/ko-filmcraft.tsv) | 시퀀스·트림·시간 편집·오디오·출력 |

`references`의 S1–S10은 [출처 목록](terminology/ko-sources.json)에 연결됩니다.
`editorial`은 이번 작업에서 의미에 맞춰 정한 선택이며 Adobe의 공식 표기 확인을 뜻하지 않습니다.
참고 출처는 용어의 배경이며, 같은 기능이 Craft에 구현되어 있다는 증거가 아닙니다.
`novice_help`는 개념 설명입니다. 실제 툴팁에 넣을 때에는 대상 명령의 코드와 일치하게
다듬어야 합니다. 이 자료는 AI가 집필·자체 검토했으며 별도의 사람 검수는 아직 없습니다.

## 우선 선택과 혼동 방지

1. **익숙한 기술어를 유지하고 설명을 붙입니다.** `스프레드`, `도련`, `커닝`, `키프레임`을
   무리하게 새말로 바꾸지 않습니다. 첫 설명에서는 펼침면, 재단 여유 영역처럼 뜻을 풉니다.
2. **의미가 다른 동작을 같은 말로 뭉개지 않습니다.** `Align`은 정렬, 쌓임 순서의 `Arrange`는
   쌓임 순서, 문서 창을 배치하는 `Arrange`는 창 배열, `Distribute`는 간격 배분입니다.
   표의 `Columns`는 열, 본문의 `Columns`는 단입니다.
3. **짧은 이름과 안내 문장은 역할이 다릅니다.** 메뉴에는 `획`, 설명에는 “도형 가장자리의 테두리”를
   사용합니다. `칠/채우기`, `개체/오브젝트`처럼 공개 문서에서도 섞이는 표현은 우선 표기를 정하고
   다른 표현은 검색용 동의어로 남깁니다. 우선 표기는 칠, 획, 개체, 색상 견본입니다.
4. **초보자가 잘못 예상할 이름에는 행동을 드러냅니다.** PDF `Redact`는 민감정보 제거를 우선하고
   Adobe의 교정은 동의어로 둡니다. 표시와 제거 적용을 나누어 설명합니다. 영상 `Razor`는 클립 분할로
   설명하여 이미지 자르기와 구별합니다. 슬립/슬라이드는 밀어넣기/밀기와 영어 동의어를 함께 찾을 수 있게 합니다.
5. **같은 말의 적용 범위를 확인합니다.** 레이아웃 프레임과 영상 프레임, 그림 마스크와 클리핑,
   디지털 서명과 서명 그림, 인터페이스 언어와 OCR 문서 언어를 구별합니다.
6. **실제 영어 키를 보존합니다.** 대소문자, 말줄임표, 단축키, `{name}` 같은 자리표시자는
   카탈로그 규칙을 따릅니다. 도움말에 적는 단축키는 Adobe 목록이 아닌 해당 Craft 도구 등록에서 읽습니다.

## 초보자용 툴팁 집필 기준

표시 순서는 **도구 이름 + 실제 단축키**, **어떻게 사용하는지**, **결과 또는 중요한 범위**입니다.
한 문장에 한 가지 행동을 담고 보통 두 문장 안에서 끝냅니다. 길어지면 대화상자의 도움말이나
“자세히” 설명으로 옮깁니다. “이 기능을 사용하면 됩니다”처럼 이름만 반복하지 않습니다.

| 대상 | 설명 예시 | 배포 전 확인 |
|---|---|---|
| 선택 도구 | 개체를 선택하고 이동합니다. 프레임 안의 그림이나 패스의 점만 고치려면 직접 선택 도구를 사용하세요. | 실제 선택·직접 선택 동작 |
| 손 도구 | 드래그하여 문서의 다른 부분을 봅니다. 페이지와 개체의 위치는 바뀌지 않습니다. | 보기 이동과 문서 편집의 분리 |
| 텍스트 인식 | 페이지 그림에서 글자를 읽어 검색과 선택에 사용할 텍스트를 만듭니다. 현재 인식 엔진이 지원하는 문자만 읽을 수 있습니다. | 설치 모델·문자 범위·PDF 저장 결과 |
| 넘친 텍스트 | 틀에 다 들어가지 않은 글이 있습니다. 프레임을 늘리거나 다음 프레임과 연결하세요. | 실제 경고 상태와 연결 명령 |
| 민감정보 제거 표시 | 제거할 영역을 표시합니다. 제거 적용 전에는 원래 내용이 문서에 남아 있습니다. | 표시·적용·저장 단계별 동작 |
| 레이어 마스크 | 레이어의 보일 부분과 숨길 부분을 따로 정합니다. 내용 자체를 지우는 대신 마스크를 편집합니다. | 지원하는 마스크 종류와 적용 동작 |
| 잔물결 편집 | 클립의 시작이나 끝을 조절하면서 뒤쪽 클립도 함께 이동합니다. 잠금과 동기화 설정에 따라 움직이는 트랙이 달라질 수 있습니다. | 잠금·동기화·다중 트랙 정책 |

도구 아이콘에는 기존 단축키를 유지하고 숨은 도구가 있는 경우 실제 동작에 맞는 열기 방법을
알립니다. 적용 대상이 없을 때에는 비활성 사유를 보여 줍니다. “항상 원본 유지”, “완전히 안전”,
“모든 언어 지원”과 같이 확인되지 않은 약속을 넣지 않습니다.

중요한 설명을 마우스 올리기에만 숨기지 않습니다. 키보드 포커스로도 도움말을 찾을 수 있게 하고,
터치 사용자는 도움말 버튼으로 열 수 있게 설계합니다. 제거·덮어쓰기 같은 중요한 결과는
툴팁뿐 아니라 확인 단계에도 표시합니다. 초보자 도움말을 줄이는 선택지를 두더라도 중요한
결과 안내는 유지합니다. 단축키와 버튼의 접근성 이름을 긴 설명으로 덮어쓰지 않습니다.

## 번역 및 도움말 적용 절차

1. 현재 앱의 영어 문자열, 도구 ID, 표시 위치와 명령 동작을 읽습니다.
2. 공통 용어를 선택하고 앱 전용 의미가 있으면 해당 용어집 행을 우선합니다.
3. 동작과 결과가 코드로 확인된 설명만 툴팁으로 연결합니다. 지원하지 않는 기능의 용어도
   참고용 용어집에는 둘 수 있지만 앱에 기능이 있는 것처럼 표시하지 않습니다.
4. 공유 `common.tsv`는 기존 번역을 변경하지 않고 앱별 카탈로그에 필요한 재정의를 둡니다.
   용어집 TSV는 런타임 카탈로그가 아니므로 그대로 앱에 넣지 않습니다.
5. 중복 키·자리표시자·말줄임표를 검사하고 실제 화면에서 줄바꿈, 글꼴, 키보드 접근을 확인합니다.
   파일 내 항목 수를 번역된 화면의 비율로 보고하지 않습니다.
6. 번역자, AI 지원 여부, 사람의 검수 여부를 해당 프로젝트의 출처 문서에 기록합니다.

기존 DesignCraft 초안에서 `Arrange`를 “정렬 및 배열”, `Gutter`를 “간격”으로 뭉뚱그린 부분은
개체 메뉴의 쌓임 순서와 단 간격으로 바로잡습니다. 창 메뉴의 Arrange는 창 배열로 구별하고,
문맥이 전달되지 않는 곳에서는 일반 명칭인 배치로 표시합니다. 모든 메뉴·툴팁의 번역 완료 여부는
별도 앱 실행으로 확인합니다.

## PdfCraft 및 DesignCraft 적용

DesignCraft 사용자 fork는 기존 카탈로그와 명령/화면 목록의 2,400개 이상 원문 키를 한국어로 채웠습니다.
기존 Craft 한국어 번역을 재사용한 항목은 이 저장소의 라이선스와 출처를 유지하며, 페이지 레이아웃
전용 문구와 도구 설명은 소스 동작과 이 용어집에 따라 새로 썼습니다. 도구 37개의 설명을 연결했고
미구현 도구 4개는 사용할 수 없다고 명시합니다. 긴 설명은 접근성 이름과 분리한 툴팁 본문에 표시하며,
마우스를 올리지 않아도 **도움말 › 도구 사용 도움말(F1)**에서 읽을 수 있습니다.
`tool.list`, `ui.tool.list`, `help.tools` 명령으로도 같은 도움말에 접근합니다.

PdfCraft는 기존 한국어 카탈로그를 보완하고 도구 그룹 23개의 초보자 설명을 추가했습니다.
모든 도구 목록에서 마우스를 올리거나 각 도구 패널의 **이 도구로 할 수 있는 작업**을 펼쳐 읽습니다.
자동화에서는 `tool_help`가 같은 설명을 제공합니다. 다국어 OCR은 로컬 Tesseract의 언어/문자 체계
모델을 사용하며, 인식 언어와 화면 언어를 별도로 선택합니다. 저장 시 비 ASCII 단어의 Unicode는
PDF ActualText로 보존합니다. 상세 동작과 시험 명령은 각 앱의 기존 문서가 소유합니다.

Rust와 Windows 빌드 도구를 설치했고 네이티브 앱에서 한국어 표시와 도움말을 확인했습니다. 카탈로그 키를
채운 수치, 실제 화면 검증, 원어민 검토는 서로 다른 상태로 기록합니다. 이 문서는 원어민 검토를
받았다고 주장하지 않습니다.

## 출처의 범위

문맥 키의 중복, 필드 누락, 출처 ID는 `python tools/check_korean_terminology.py`로 검사합니다.
`--export-to <path>`를 지정하면 정본 TSV에서 읽기용 Markdown 용어집을 생성합니다.

자료는 Adobe가 직접 게시한 한국어 도움말과 Tutorial Builder 문서입니다. 2026-10-24에
읽었으며 페이지는 갱신되거나 다른 주소로 연결될 수 있습니다. iPad 자료는 용어 참고로만 쓰고
데스크톱 조작법으로 일반화하지 않습니다. 글꼴·아이콘·튜토리얼 실습 에셋은 수집하지 않습니다.
원문 전송 기록과 참조 화면은 공개할 소스 파일과 분리하여 gitignored `plan/research/`에 보관합니다.

이번 조사에서는 브라우저로 각 본문을 읽고 첫 화면과 전체 화면을 기록했습니다. 별도 HTTP
원문 보관 요청은 403 응답을 받아 그 거부 응답 자체를 WARC에 보존했습니다. 따라서 WARC가
본문의 성공적인 원문 수집이라고 주장하지 않습니다. 출처 확인은 읽을 수 있었던 공개 페이지와
브라우저 참조 화면에 근거합니다.
